# About

I am a Computer Science undergraduate passionate about transforming data into intelligent solutions.

My long-term objective is to become a **Data Engineer**, specializing in building scalable data platforms, and eventually grow into an **AI Engineer / Data Scientist** focused on machine learning, LLMs, and production AI systems.

While my career direction is centered around Data and AI, I possess a strong software engineering foundation with experience building full-stack applications, REST APIs, backend services, cloud deployments, and modern web interfaces.

Rather than chasing technologies, I focus on understanding systems—how software is designed, data flows through applications, and intelligent models are deployed at scale.
